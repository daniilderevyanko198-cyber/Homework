## 🌟 Общая информация

Игровой центр представляет собой приложение с графическим интерфейсом, объединяющее две популярные игры. Все игры написаны на Python с использованием встроенной библиотеки `tkinter`, что обеспечивает легкий запуск без установки дополнительных зависимостей.

### Особенности:
- 🎨 Современный дизайн с темной темой
- 🖱️ Полностью управление мышью
- 🎯 Интуитивно понятный интерфейс
- 🔄 Возможность играть несколько партий подряд
- 📊 Статистика и история ходов
- 🎵 Визуальные эффекты и анимации

---

- **Операционная система**: Windows, macOS, Linux
